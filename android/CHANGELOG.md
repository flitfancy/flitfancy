# Android 更新记录

## 0.2.0 — 2026-10-04

- 新增蓝牙/Wi-Fi 采集方式选择、兼容板扫描、附近设备权限、系统蓝牙开启和加密配对。
- 新增按协议 1 读取 BLE 分片快照：串行 GATT、订阅通知、请求编号、型号/协议校验、完整性与容量检查、超时断开及自动重连。
- 与 Wi-Fi 共用原 CSV 解析、Room 去重缓存、HTTPS 配对和确认上报；升级保留身份、缓存和原地址。切换连接方式先暂停。
- 显示最近读板与上传时间，避免把主机配对成功当成板子数据已接入。
- 仅完成 App 端；固件 1.3.5 尚无手机数据服务，需后续按照 BLE_PROTOCOL.md 扩展并完成实板验证。
