# 云萤 · FlitFancy

这里是云萤，我的个人网站，也是小流萤的家。

我在这里写日记，记下和她的一些小事；也放几篇短文，收集沿途的见闻。想到的、做出来的，还有那些暂时想不明白、还没做成的东西，都慢慢留在这里。

后来，也把自己做的板子接了进来。看看此刻的温度，听听周围的声音，放一首喜欢的歌，再和她聊几句。电脑上的应用、文件和一些日常会用到的东西，也慢慢有了各自的入口。

很多东西还在一边做，一边改。想到什么，就试着添一点；哪里不顺手，就再调整一下。慢慢做成自己喜欢的样子。

萤火飞掠，热爱无限…

[访问网站](https://flitfancy.com) · [更新日志](CHANGELOG.md) · [运行与部署](docs/OPERATIONS.md)

## 网站里有什么

| 页面 | 内容 |
| --- | --- |
| 首页 | 一片夜空，一些文字，还有可以陪你玩一会儿的萤火虫 |
| 旅途 | 我和她的日记，眼下正在做的事，以及留给以后的锚点 |
| 见闻 · 星弦 | 把事、理、物、人、地放进一颗颗星球，再用弦连起它们之间的关系 |
| 关于 | 把一些想法写成短文，放进卡牌里，再选一篇展示给你 |
| 存在 | 看看周围的变化，听声音、放音乐，也能继续和她聊天 |
| 控制台 | 照看本机服务，打开常用应用，也把文件送去 NAS |
| 资源 | 把一路做出来的东西整理好，放一些资料、固件和下载入口 |

见闻里有事、理、物、人、地，星球之间也有远近和联系。分类用淡淡的颜色区分，弦有三档强弱：淡的若有若无，强的就能看得清楚一些。星球用了水星到冥王星的样子，也加了月球；贴图的来源与授权放在 [素材说明](docs/assets/planets/CREDITS.txt) 里。

短文保存后会先留在卡牌库，点“设为展示”才会更新关于页。写下来和拿出来给人看，可以是两件事。

做出来的东西放到资源页，也可以继续补资料、添版本。登录后在资源旁点“编辑”，就能修改标题、简介、详情和栏目。“保存修改”后先留在本机，点“发布更新”才会更新公开页面；原来的附件和版本历史都保留，上传新文件时也会追加一个版本。

## 存在与控制台能做什么

- **存在 · 现实感知**：看看感知板传回的六路环境数据和手表心率。能看此刻，也能回头看变化；心率历史登录后查看。
- **存在 · 电脑使用**：看看一天的时间花到了哪里。登录后可以查看 ActivityWatch 的活跃时长、每日趋势和应用分布，按天的汇总长期留在本机，也可以导出。原始窗口标题不进入网站归档。
- **存在 · 侧耳倾听**：接上 FIREFLY VOICE，听听周围的声音。可以看双麦电平、调增益、录音和识别；音乐拖进来就能播放，也有歌词和固件升级入口。
- **存在 · 有求必应**：把本机的 AstrBot 接进来，继续和她聊天，翻翻历史，也看看她现在回复到哪里了。
- **控制台 · 本机启动**：把常用应用或脚本的路径放进来，留成一个个图标。下次想用时，点一下就在电脑上打开。
- **控制台 · 服务管理**：后端和隧道从控制台启动，音频和感知从存在页启动。开机启动与自恢复也可以按需要配置。
- **控制台 · 刷新心跳**：看看哪些数据刚读过，花了多长时间，有没有失败。记录来自后端实际完成的读取，页面查看同一份记录；还没读过的项目显示“按需”。后台采集的情况，继续看各模块自己的状态。

设备控制、电脑使用记录和私有对话需要登录。在“存在”或“控制台”页，再点一次当前导航项，就能找到登录入口；同一站点、同一标签页内切换页面会保留会话。网站配置和访问记录也在控制台管理面板里。环境与最新心率快照保留公开展示，心率历史需要登录。

文件也可以从这里送去 NAS。控制台里的“全界之桥”支持拖入或选择文件、文件夹，保留目录层级，看接收和保存的进度，也能暂停、续传和重试。它沿用管理员登录，接入说明放在 [桥接口](backend/BRIDGE.md) 里。

如果你也想搭一份，下面写了怎么开始。板子、音频服务、AstrBot 和隧道需要另外配置；想到什么，再慢慢接进来。

## 如果你也想跑起来

以下命令从仓库根目录执行。项目 CI 使用 Python 3.14 和 Node.js 24；Windows 服务脚本及桌面助手需要 Windows。

```powershell
# 首次使用：创建自己的管理员账号，按提示输入密码
py -3.14 backend/server.py --set-password admin

# 启动网站后端
py -3.14 backend/server.py
```

随后打开 [本机存在页](http://127.0.0.1:2671/presence.html) 查看感知、音频与对话，或进入 [本机控制台](http://127.0.0.1:2671/console.html) 管理服务与启动应用。网站后端使用 Python 标准库和 SQLite；仅启动后端即可查看页面，设备数据与音频功能需要对应服务在线。

若希望从网页打开本机应用，在已登录的 Windows 桌面运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install_launcher_agent.ps1
```

随后登录控制台，在“本机启动”中粘贴路径、拖入路径文本或使用“本机选择”。支持 `.exe`、`.lnk`、`.bat`、`.cmd`、`.ps1`、`.py`，可配置参数和运行目录。浏览器拖入文件时可能只提供文件名，需要补全路径。

桌面助手随 Windows 用户登录启动。后端验证网站登录并写入本机队列，助手领取请求后启动应用；电脑尚未登录桌面时，启动区显示“桌面未连接”。详见 [本机启动区](docs/LOCAL-LAUNCHER.md)。

## 数据与权限

管理账号和密钥保存在本机配置或 Cloudflare 密钥变量中。`backend/ai_local.json`、`backend/data/` 和传感器运行数据被 Git 忽略，下载代码不会把我本机的这些数据一起带走。

日记、短文、星球等内容按各自发布流程同步到云端。短文草稿与本机启动卡片不进入公共 Worker；私有对话经过本机服务，实际模型调用由对应服务配置决定。

传感器明细在 SQLite 中默认保留最近 14 天，完整原始 CSV 单独归档；这个保留策略不清理日记等内容。详见 [数据保存与备份](docs/OPERATIONS.md#感知数据保存边界)。

## 开发与检查

功能还在慢慢加，也需要一边做一边整理。现在前端按页面和控制台模块拆分，后端分开处理认证、存储、同步、音频和启动任务。继续加东西时，尽量沿用这些边界，照顾好已经在用的功能和数据。

```text
docs/           公开页面、前端模块、资源与使用文档
backend/        Python 本机后端、桌面助手与后端测试
cloudflare/     Worker 模块、云端绑定与前端检查入口
scripts/        Windows 安装/启动/守护、版本管理与数据维护
tests/          前端、Worker、Windows 脚本及数据回归测试
data/sensors/   本机感知原始数据，除说明文档外不入库
```

在 Windows 下执行完整检查：

```powershell
cd cloudflare
cmd /c "pnpm install --frozen-lockfile"
cmd /c "pnpm run check:all"
```

检查包含前端与 Worker 测试、页面骨架、版本一致性、样式检查、Worker dry-run 构建及隔离后端冒烟测试。Windows 专用功能还有 `tests/` 中的网关、守护和传感器脚本测试。

修改 HTML 引用的资源时，通过 `scripts/set-version.mjs` 统一资源版本并更新日志。纯说明文档调整不需要升级页面资源版本。协作与发布约定见 [AGENTS.md](AGENTS.md)。
