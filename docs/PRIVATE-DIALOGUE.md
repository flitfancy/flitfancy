# 私有对话接入说明

对话能力始于版本 1.14.0，版本 1.18.0 起位于“存在”页。本机及经管理员登录的存在页使用 `console-dialogue.js`；公开站点仍使用
原 `console-chat.js`。私聊数据不保存到 sessionStorage/localStorage；若小流萤选择咨询外部模型，整理后的咨询内容会经过 Cloudflare 发送给所选服务。

文字请求路径：页面 → 2671 `/api/dialogue/messages` → 固定回环 7865 → AstrBot 正常事件队列。
状态、最近 40 条历史沿用 `/api/audio/status` 返回。远程读取也必须通过管理员验证，响应 no-store。
网页显示待唤醒、听取、识别、思考、准备语音、回答及异常；历史统一从 AstrBot 获取。
网页回复仅文字，板子来源仍使用语音；普通 QQ 文本/语音保留各自回复策略。

权威历史在电脑的 AstrBot 数据库，FFV 为展示缓存；浏览器刷新或 QQ 下线不会删除历史。
现有 Firefly Memory 插件继续记录聊天与注入视觉，没有在本轮新增长期记忆提炼系统。

小流萤的网页提供“新对话”和“历史对话”：它们调用 AstrBot 原有会话管理器，网页、QQ 和板子始终共用所选会话。新对话从空白开始并沿用当前人设设置；打开旧对话后继续该对话，旧记录不会被删除或复制到网页数据库。网页目前展示所选对话的最近 40 条，完整记录仍在 AstrBot。切换会等待正在处理的同一会话，并在网页消息正在处理中阻止切换；状态不明确时不自动重试新建。另一个客户端如果也操作 AstrBot 的会话选择，网页会在下次同步时跟随。

小流萤会话切换依赖 `integrations/firefly_sessions/` 中的 FFV 与 AstrBot 语音桥扩展。安装脚本先校验源和已安装插件一致、备份将修改的文件并验证备份，不读取 AstrBot 配置，也不启动或重启服务。FFV 需要重启，AstrBot 语音插件需要重载或 AstrBot 重启后该能力才上线；没有扩展时原有聊天仍可用，会话控件禁用。

私有聊天使用 `dialogue_enabled` 本地配置（默认 true）；访客 `chat_enabled` 独立，原值不变。
Windows 网站后端启用独占端口，第二次启动直接失败，避免多个进程混用接口版本。

验证包含私聊路由、状态映射、重复提交、断线后禁用、纯文本渲染、远程未登录拒绝、CSRF、独占端口。
开发现场网页实测已回答前一轮 QQ/板子会话的“蓝色风铃”，没有触发扬声器播放。

## 模型直聊与小流萤咨询

管理端“存在 → 有求必应”可在“小流萤”和“模型直聊”之间切换。小流萤的原有历史继续由 AstrBot 保存，网页展示当前会话最近 40 条；模型直聊另存独立会话：管理员历史保存在本机网站数据库，现有管理员角色共同可访问；访客历史保存在访客自己的浏览器，同一浏览器配置文件的使用者也能看到。新建对话不带其他会话的消息，打开旧会话可继续；调用云模型时只发送该会话最近的完整问答，并限制消息总量。历史保留与服务商的提示词缓存是两回事：新对话不会自动载入旧记录，服务商缓存也不是持久记忆。退出管理清除网页显示，不删除本机历史；清理浏览器站点数据可能删除访客历史。模型或接口改变后，旧会话仍可查看，但须切回原模型或新建对话，避免把旧内容发给另一个服务。

登录管理端后，在原有“控制台 → 管理 → 模型选择”中选择原 Cloudflare 接口、DeepSeek、MiMo、OpenAI 或自定义兼容接口。新接口填写模型名称、HTTPS 接口根地址与密钥；各服务的设置分别保留。模型密钥写入对应的 Cloudflare Worker 加密变量，不回显，不写入网站后端配置。清理旧模型密钥后，“原 Cloudflare 接口”及原访客聊天不再有可用密钥；要重新使用 DeepSeek，可选择 DeepSeek 并输入新密钥。修改其他接口地址时须重新输入该服务的密钥，且密钥与地址绑定，避免误发到新地址。云端 Worker 无法使用电脑的回环地址。OpenAI 请求使用 Responses API 的 `store: false`，其他服务使用兼容的 Chat Completions 接口。

网页模型直聊可选“关闭 / 仅管理员 / 所有访客”，默认仅管理员；这不改变小流萤的本地对话和咨询。访客对话直接经过云端 Worker，不读取私有历史；管理端和小流萤的请求由本机使用原有 Worker 管理连接转发。访客调用有每 IP 速率限制及 Cloudflare D1 保存的每日次数上限（默认 20 次，北京时间，含失败或结果不明的请求）。次数上限不等于各服务的实际费用上限。公网 Worker 和主站页面都需要部署对应版本。

如需在网站输入新密钥，先创建只限该 Worker 的 Cloudflare Individual Workers Editor 令牌，在“首次配置 Cloudflare 管理授权”中输入一次。网站后端只转发该令牌到固定 Cloudflare API，将其存为 Worker 加密变量，不保存在本机配置。该令牌不仅能更新密钥，也能修改或部署该 Worker，直到在 Cloudflare 撤销；控制台管理账号和该 Worker 的安全都很重要。模型设置中的密钥与管理令牌均不会显示原值。

`integrations/astrbot_plugin_firefly_consult/` 是小流萤的可选咨询工具。将整个插件目录放入 AstrBot 数据目录的 `plugins/` 并重启 AstrBot 后，原本地模型保留；在主人的 QQ 私聊及与其共用会话的网页/板子消息中，可按需调用 `consult_model`，使用控制台选中的服务。明确请教外部模型或匹配技术问题的本地规则时会先咨询；其他问题仍可由本地模型选择工具，规则不是对所有复杂问题或自然语言禁用表达的完美识别。每轮最多一次，群聊和其他用户不能调用云端。咨询时发送问题和当前 AstrBot 会话最近最多六条简短文字，不检索其他会话、不自动发送图片。检测到常见凭据时停止本轮咨询，但检测无法穷尽所有密钥格式，不要在对话中输入密钥。工具返回的是建议而非验证结果，也不会直接操作设备。接口与能力边界见 [模型网关](MODEL-GATEWAY.md)。

每次咨询的实际提问、服务与模型名称、原始答复或失败状态写入本机 `backend/data/model-consultations.sqlite3`；管理员在“存在 → 有求必应 → 她的咨询”查看。它不混入用户发言或公开访客历史；退出管理会清空网页显示，但不会删除本机记录。插件与网页共用云端模型配置和本机 Worker 管理连接；默认读取 `S:/FlitFancy/site/backend`，可通过 `FLITFANCY_BACKEND_DIR` 覆盖。

网页更新后台代码后需重启网站后端，再刷新并重新登录；AstrBot 插件要在 AstrBot 启动后加载。API 未配置、不可达或额度不足时会显示失败，不自动切换对话服务或重复请求。两条路径的 API 调用均计入所选服务账户的额度。
