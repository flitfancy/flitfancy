# 私有对话接入说明

对话能力始于版本 1.14.0，版本 1.18.0 起位于“存在”页。本机及经管理员登录的存在页使用 `console-dialogue.js`；公开站点仍使用
原 `console-chat.js`。私聊数据不保存到 sessionStorage/localStorage，不发往公开 AI 接口。

文字请求路径：页面 → 2671 `/api/dialogue/messages` → 固定回环 7865 → AstrBot 正常事件队列。
状态、最近 40 条历史沿用 `/api/audio/status` 返回。远程读取也必须通过管理员验证，响应 no-store。
网页显示待唤醒、听取、识别、思考、准备语音、回答及异常；历史统一从 AstrBot 获取。
网页回复仅文字，板子来源仍使用语音；普通 QQ 文本/语音保留各自回复策略。

权威历史在电脑的 AstrBot 数据库，FFV 为展示缓存；浏览器刷新或 QQ 下线不会删除历史。
现有 Firefly Memory 插件继续记录聊天与注入视觉，没有在本轮新增长期记忆提炼系统。

私有聊天使用 `dialogue_enabled` 本地配置（默认 true）；访客 `chat_enabled` 独立，原值不变。
Windows 网站后端启用独占端口，第二次启动直接失败，避免多个进程混用接口版本。

验证包含私聊路由、状态映射、重复提交、断线后禁用、纯文本渲染、远程未登录拒绝、CSRF、独占端口。
开发现场网页实测已回答前一轮 QQ/板子会话的“蓝色风铃”，没有触发扬声器播放。
