FFS 固件

固件 1.3.0 · 暂缓发布

1.3.0 二进制与源码包发现内置了家庭网络凭证，已临时下架。

正在改造为"首次上电配网"流程，凭证不再编译进固件。

1.3.0 更新内容

  • 断链自愈：心跳 PONG 超时 15 秒后主动断开重连，链路中断最迟约 15–20 秒恢复（此前可能断档数小时）。
  • 闪烁检测：AS7341 FLICKER 开启，每约 30 秒检测一次光源频闪（0=无闪烁，1=有闪烁但频率未知，100/120=Hz），随 CSV 上报。
  • RSSI 进流：每行数据附带 WiFi 信号强度（rssi_dbm），便于断联诊断。
  • CSV schema 3 → 4（表尾追加 flicker_hz / rssi_dbm 两列，不位移既有字段）。

烧录方法

  1. 安装 PlatformIO（VS Code 扩展或命令行）。
  2. 板子 USB 接电脑（整板版为原生 USB，COM 口以设备管理器为准）。
  3. 直接烧录二进制（无需源码）：
    esptool.py --chip esp32s3 --port COM7 write_flash 0x10000 firefly-fw-1.3.0.bin
  4. 或解压源码包后用 PlatformIO 编译烧录：
    pio run -e esp32s3_n16r8_usb -t upload --upload-port COM7
  5. 烧录后板子自动复位并恢复采集（无需手动发命令）；数据经 TCP 7777 推送到监听器。
