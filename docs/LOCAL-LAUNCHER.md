# 本机启动区

位置：控制台“侧耳倾听”下方。沿用隐藏式登录，登录后显示卡片；所有读取、添加、编辑、删除、选择与启动 API 均校验管理员会话，本机回环请求也不例外。

## 第一次启用

在要打开应用的 Windows 桌面登录账户内运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install_launcher_agent.ps1
```

安装器在当前用户的“启动”文件夹中添加 `FlitFancy Launcher.vbs`，并启动无控制台窗口的 Python 桌面助手。无需修改注册表，也不影响原来的开机后端任务或音频服务。可以用 `-Python <python.exe 完整路径>` 指定助手解释器。

后端允许在开机后台会话中运行；助手必须在桌面会话中运行。未登录桌面、助手退出时，网页不会排队等待应用日后启动。锁屏时应用可能在锁定的桌面会话中打开，解锁后可见。

移除登录自启动入口：运行安装器并加 `-Remove`。当前助手会在注销桌面时退出，保存的卡片和原始文件不删除。

## 添加卡片

- 粘贴 `.exe`、`.lnk`、`.bat`、`.cmd`、`.ps1` 或 `.py` 的完整本机路径。
- “本机选择”会在运行助手的电脑上弹出文件选择窗口；远程使用也应到该电脑完成选择。
- 拖入完整路径文本可直接填写。拖入文件时，浏览器一般只提供文件名；助手可匹配桌面同名文件，找不到或重名时需要补全路径。不会上传或执行浏览器传入的文件内容。
- 默认名称取文件名。脚本默认隐藏终端窗口，应用和快捷方式默认显示窗口。
- 高级选项支持运行目录、逐行参数和 Python 解释器。每行参数原样传递，无需给带空格的路径加双引号。
- 批处理经过 CMD 启动，路径与参数禁止 CMD 特殊字符；请把复杂逻辑写进自己保存的脚本中。

点击整张卡片启动；编辑和移除位于卡片底部。移除只删除启动记录。启动结果表示系统已接受启动或脚本已快速完成，不是持续运行监控；应用自身的退出不会自动重启。

## 数据与进程边界

卡片及请求保存在 `backend/data/launcher/launcher.db`，不会同步到 Cloudflare。目录 ACL 仅授予当前 Windows 用户和 SYSTEM 权限。助手不开放网络端口，从本机私有 SQLite 队列读取工作。

网页的启动接口只接受已保存的卡片 ID。每个请求只能领取一次，未领取的请求 10 秒后作废；编辑/删除卡片会取消未执行的旧请求。重复点击有短间隔限制。执行时重新检查文件，使用参数数组启动应用和脚本，批处理另做特殊字符校验。

测试使用隔离临时文件和数据库：`py -3 backend/launcher_test.py`。正式页面不带示例启动卡片。

## 启动项图标

启动区自动读取 Windows 为应用、快捷方式或脚本分配的图标，以图标和名称展示。图标仅通过已有管理员接口返回，不上传到公共网站。提取在后台进行并缓存，第一次打开可能先显示默认图标；读取失败时仍可正常启动。替换文件内部图标后，重启后端可清除图标缓存。
